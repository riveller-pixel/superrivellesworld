# Context & Architecture Decisions

## Project Overview
Super Rivelles Peris World is a retro-modern 2.5D canvas platformer. The goal of this task is to deliver 4 major features:
1. Secret Star World (Mundo Especial Galáctico)
2. Boss Rush Arena Mode
3. Expanded Royal Closet & Trophy Boutique
4. Next-Gen Visual & Audio Polish

## Constraints & Requirements
- 100% test pass rate across existing 153 test_mechanics.js tests + new tests.
- 60 FPS Canvas performance, responsive mobile touch controls, offline PWA readiness.
- Strict dispatch-only orchestrator rules (all implementation, investigation, and test running delegated to subagents).
- Binary veto on integrity violations from Forensic Auditor.
